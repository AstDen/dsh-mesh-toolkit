# 0.5.1 — benchmark-driven fixes, threshold parity, version stamping

Версии пакетов: **mesh-build 0.5.1 · mesh-stl 0.3.1 · sim-core 0.4.1** (плюс общий
регрессионный набор `benchmark/`). Релиз закрывает 16 из 18 дефектов, найденных
глобальной проверкой инструментария (`benchmark/runs/20261125-1805`, 61 кейс:
45 PASS / 15 FAIL / 1 GAP).

## Что теперь работает иначе

**mesh-build**

- `lib/precheck.js` (новый): STL вне домена (мм × 0.001), бюджет ячеек фоновой сетки,
  проверка доменного патча после мешинга, отказ cfMesh на мм-геометрии с точным уровнем октодерева.
  Геометрия больше не «обрезается молча».
- `scaffold`: `refinementLevels` принимает пару `[min, max]` (было `(2 2)`, эталон требовал `[1, 2]`);
  неизвестный ключ поверхности — явная ошибка вместо молчаливого `defaultLevel`;
  `meshQualityDict` пишется по профилю гейта (`maxNonOrtho`, `minVolRatio`, `minTwist`)
  — больше не нужно править словарь руками, как в exp-022.
- `gate`: если в cfMesh-кейсе нет `system/fvSchemes`/`fvSolution`, минимальные копии
  синтезируются в overlay (на метрики влиять не могут), в ответе — `synthesized` и advisory.
- `mesh_check`: свежесть паспорта считается ДО перезаписи — устаревшая сетка больше не выглядит «fresh».
- `mesh_build`/`mesh_check` возвращают `version {reported, onDisk, stale, warning}`;
  паспорта и манифесты кейсов штампуются версией из `package.json` на момент вызова.
- Каталоги карточек mesh-build и mesh-stl объединены в один store — 33 карточки,
  запросы про org14/cfMesh/watertight находят нужное (F3/F4/F5/F7).

**mesh-stl**

- Семейство `stratified-channel` (закрывает GAP D3): две замкнутые STL-области
  по плоскости интерфейса, пресет `channel_10x10x20_h8`.
- `stl_check`: считает non-manifold рёбра; «сырой» не-watertight STL теперь FAIL,
  а не PASS с предупреждением.

**sim-core**

- Синтез словарей для гейта, CHANGELOG, версия 0.4.1.

**benchmark**

- `TESTS.md`: 19 исправлений протокола (домен E1, пары уровней, minVol по правилу
  `h_min³/6`, единицы cfMesh в метрах, `bodies = clusters`, H1/H2/H9/G8) + раздел 18.
- `scripts/fluid_point.py`: точный зонд по bucket-индексу, `--max-seconds`,
  сообщение о лучшем достигнутом зазоре — не висит на плотных упаковках.

## Проверено

- `experiments/_scratch/verify-fixes.mjs` — 15/15; `verify-actualize.mjs` — 10/10
  (пороговый паритет словаря, реальный snappy-прогон 2584 ячейки, гейт PASS).
- `scripts/smoke.mjs` обоих плагинов — SMOKE OK.
- Повторные прогоны бенчмарка: D1 с корректной точкой (ENV-2), V1–V4 воспроизводят
  эталоны exp-019 (2584 ячеек, 9.7073° / 25.2146°, gmsh 1135 тетраэдров).

## Важно

- **Перезапустите DSH** после обновления: живой процесс держит старый ESM-граф,
  поэтому `mesh_hints()` может ещё показывать `reported: "0.2.0"` — блок `version`
  в ответах инструментов прямо скажет, что делать.
- `gate.minVol` по-прежнему абсолютный объём: правило `h_min³/6`, значение по умолчанию — выключено.
